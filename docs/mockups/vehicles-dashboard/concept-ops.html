Заметки к реализации

Правило светофора

  • Пора ТО (rose): остаток ≤ 0 км или с последнего ТО прошло > 365 дней.
  • Скоро ТО / нет данных (amber): остаток ≤ 20% интервала или нет ни одной записи VehicleServiceLog.
  • В норме — нейтральный серый рельс. Цветом кричат только проблемные карточки, иначе светофор перестаёт читаться.
  • Занятость (свободна / выдана / забронирована) — отдельная ось, живёт в пилюле справа, рельс не красит.

Нужно от бэкенда

  • serviceIntervalKm — новое поле на Vehicle, задаётся по машине (Ford 10 000, Ивеко 8 000). Без него шкала «До ТО» рисуется пустой.
  • mileageDelta30d / 90d, avgKmPerShift — из VehicleMileageLog.
  • revenueRub, shiftsCount, utilizationDays, utilizationStrip[30] — из BookingVehicle + Booking.
  • serviceSpendRub, serviceCount — из VehicleServiceLog за период.
  • upcomingBookings[] вместо одной activeBooking — карточке нужна и текущая, и ближайшая.
  • Параметр периода ?period=30d|90d|365d для денежных агрегатов.

Роли

  • SUPER_ADMIN — всё, включая экономику и кнопки действий.
  • WAREHOUSE — без блока «Выручка / Обслуживание / Итог»; кнопки «ТО» и «Пробег» доступны.
  • TECHNICIAN — read-only: без экономики и без кнопок действий, остаётся «Открыть карточку».
