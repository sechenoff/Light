Рабочий стол кладовщика v2 — концепция

Сейчас киоск — это «выбери операцию из 3 кнопок → список → чек-лист». Чек-листы отточены и остаются как есть KEEP, но вокруг них нет рабочего места: кладовщик не видит план дня, просрочку, свою выработку и поломки. v2 меняет каркас: постоянная навигация из 5 разделов (таб-бар на планшете/телефоне, левая колонка на десктопе) + новый домашний экран «Смена».

5 разделов

  • Смена NEW — план дня лентой, алерт просрочки, счётчики, быстрые действия
  • Выдача KEEP — список → текущий чек-лист (степперы, добор, водители)
  • Приёмка KEEP — список → текущий чек-лист (3 исхода, фото, потеряшки)
  • В работе UPGRADE — сроки: фильтры Просрочено/Сегодня/Все, звонок клиенту, «Принять»
  • Журнал NEW — учёт работы (сессии с длительностью) + статистика недели + поломки

Новый бекенд (3 эндпоинта)

  • GET /api/warehouse/shift — лента дня (выдачи+возвраты с временем и статусом), счётчики, просрочка
  • GET /api/warehouse/journal?days=7 — завершённые ScanSession: оператор, операция, бронь, позиций, длительность
  • GET /api/warehouse/problems — активные Repair + ProblemItem под warehouseAuth (сейчас только под JWT)

Все данные уже в БД (ScanSession.startedAt/completedAt, Booking.endDate, Repair, ProblemItem) — только чтение, ноль миграций.

Решения и что остаётся как есть

  • Чек-листы выдачи/приёмки не переделываются — степперы, «Все выдано», добор, водители, 3-исходная приёмка, фото поломок уже отработаны. Они просто получают таб-бар снизу вместо полного ухода назад.
  • Таб-бар вместо «выбора операции» — переключение разделов одним тапом из любого места. Экран «Что вы делаете сейчас?» исчезает; после входа сразу «Смена».
  • Бейджи на табах — Приёмка показывает счётчик просроченных (rose), «В работе» — общее число активных (amber).
  • Иконки — SVG (Lucide-стиль), не эмодзи: единый штрих 1.9px, темизация цветом. Touch-таргеты ≥44px.
  • Поломки живут внутри Журнала на телефоне (карточка-ссылка) и отдельным пунктом на десктопе — 5 табов держим, шестой не плодим.
  • PIN-логин без изменений — токен-контракт, SA/WH bypass, deep-link ?booking= сохраняются.
  • «Смена» деградирует мягко: нет операций на сегодня → пустая лента с «Сегодня выдач нет», алерт только при просрочке.
  • Журнал «Мои/Все» — по workerName сессии; кладовщик видит и свою выработку, и общую картину склада.
  • Регистрация поломки без возврата — с экрана Поломок, юнит-пикер + причина + фото (использует готовый RepairPanel-механизм).
  • Реализация по фазам: 1) каркас-навигация + Смена · 2) В работе со сроками · 3) Журнал + статистика · 4) Поломки. Каждая фаза деплоится отдельно.
