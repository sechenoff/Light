Эскиз 2 · приёмка с карточки брони

«Принять возврат»: вернули не всё

Обычный случай остаётся в одно нажатие — «Вернули всё». Позиции, взятые на 2 смены, уже отмечены «остаются по плану». Если клиент оставил что-то ещё, сотрудник отмечает, сколько вернули; сверх оплаченного — сразу видна сумма дополнительной сметы.
