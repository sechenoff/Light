Два сюжета: M1 и M4 — большая бронь СМ-2026-0244 (55 позиций), M2, M3 и M5 — бронь
СМ-2026-0231 (7 позиций), чтобы документы и киоск помещались на экран.

## Решения

- **Контрол смен.** На компьютере — поле в ячейке, тот же жест, что у договорной цены:
  клик, ввод, Enter / Esc, ↑↓, «↺», индиго для своего значения. Степпер в каждой из 55
  строк был бы шумом. На телефоне — чип «1 см», открывающий шторку с крупным степпером:
  в поле шириной 30 px пальцем не попасть.
- **Реестр.** Продолжение — вложенная строка сразу под основной бронью («↳», пунктир
  сверху), со своим чекбоксом, заливкой и кнопками. Отдельная строка с бейджем уезжает
  от родителя при сортировке и на другую страницу. Если фильтр скрывает основную бронь,
  над продолжением остаётся её тонкая серая строка.
- **Срок оставленного.** Сегменты «до конца оплаченного / +1 смена / +2 / дата…».
  У позиций без плана первый сегмент — «+1 смена»: оплаченное у них уже кончилось.
  Под сегментами — дата возврата и сумма.
- **Цвета.** Бирюзовый — «у клиента», как статус «Выдана». Индиго — «по плану», как
  своё число смен в форме. Янтарь — «сверх оплаченного», держатель и «под ответственность».
- **Главная кнопка считает:** «Принять 53 позиции», «Принять 16 ед.».

## Вопросы владельцу

1. Срок оставленного при опоздании считать от приёмки («+1 смена» — до ср 14:20), как
   нарисовано по решению 7? Или от конца брони?
2. Показывать кладовщику в киоске сумму доп. сметы или только «будет доплата»?
3. «Разнести по продолжениям» включать по умолчанию, если у продолжения есть долг?

## Сборка и снимки

```bash
W=<worktree с node_modules>   # tailwindcss и playwright
node _src/build.cjs $W _src/m1.html m1-form-shifts.html _src/m2.html m2-smeta-documents.html \
  _src/m3.html m3-kiosk-return.html _src/m4.html m4-return-dialog.html \
  _src/m5.html m5-booking-family.html _src/idx.html index.html
node _src/shot.cjs $W _shots index.html m1-form-shifts.html m2-smeta-documents.html \
  m3-kiosk-return.html m4-return-dialog.html m5-booking-family.html
```

`<!--@include имя-->` вставляет `_src/_part-имя.html`. Снимок печатает ширину страницы
и элементы, вылезшие за край вне скроллера.
