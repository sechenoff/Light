# Обучение словаря сленга — раунд 2 (2026-09-02)

Цель раунда: сверить заявки гафферов за два месяца со сметами, которые по ним
собрал сотрудник, и на этой разнице доучить словарь и автоподбор каталога.
Первый раунд — `docs/slang-training-2026-07-16/`.

## Источники

- Экспорт Telegram-группы «Svetobaza x Kirillin» («Svetobaza Export August»):
  сообщения 02.07–04.08.2026, 26 текстовых заявок, 33 xlsx-сметы сотрудника
  из тем «Списки/даты», «Погрузки», «#Сметы».
- База системы: 158 броней за период и 217 подтверждённых фраз словаря.
- Заявок за 05.08–02.09 в экспорте **нет** — для следующего круга нужен свежий
  экспорт (Telegram Desktop → карточка группы → Export chat history, JSON).

## Метод

1. **Пары** (`pairs.json`) — 12 заявок надёжно сопоставлены со сметой и бронью
   по дате и гафферу (Гена Белых ×3, Петя Куб ×3, Захар Радомский ×3,
   Xokage ×3). 11 заявок остались без пары: PDF-вложения, «список позже»,
   сметы без заявки в тексте — см. `pairs.json → notes/unpaired`.
2. **Эталон** (`truth.json`) — 366 строк заявок размечены вручную: что
   сотрудник реально поставил в смету по каждой строке (одна строка может
   раскрываться в несколько позиций, «плоскотница» — в семь).
3. **Сверка** — те же заявки прогнаны через боевой распознаватель
   (`parse-gaffer-review` на проде) и сравнены с эталоном построчно.
   Итог до правок: из 369 строк 266 верно, 21 частично, 59 **уверенно неверно**,
   11 пропущено. Уверенные ошибки опаснее пропусков — такие позиции уезжают в
   смету без вопроса. Разбор — `wrong-picks.json` (47 кейсов) и
   `matcher-issues.json` (9 системных причин).
4. **Синтез и скептики** — предложения по словарю прошли двух независимых
   проверяющих; принятое — `aliases-applied.json`, отклонённое с причинами —
   `aliases-rejected.json` (25), дыры каталога — `catalog-gaps.json` (10).

### Код

- PR #204 — количество и пробелы не мешают псевдонимам; полная фраза остаётся
  в скоринге («K5600 Joker-800» ≠ Joker-400); слитные псевдонимы ищутся напрямую.
- PR #205 — семьи позиций: фраза без размера («хейзер», «трубный бум»,
  «автополя», «мбю») не выбирает вариант наугад, а уходит на проверку и
  AI-подбор; близкие конкуренты (32/380 vs 63/380) — на проверку; «все» =
  всё наличие; «400x + френель» разбивается на прибор и линзу.
- PR #206 — автообучение пишет псевдонимы без количества (но не срезает
  число-модель: «Джокер-800» остаётся «джокер 800»); промпт разбирает
  перечисления через запятую и «Рама 8 (мбю, сильвер, …)», пропускает
  служебные строки (они давали лишние доставки на 24–49 тыс. ₽).

Проверено живым подбором на проде: все одиннадцать контрольных фраз дают
ожидаемый результат.

**Оговорка по комплектам.** Комплект-позиция — отдельная строка каталога со
своим наличием, а не спецификация: система не знает, что «Рама трубная 20х20»
состоит из восьми труб и углов. Поэтому трубы, ушедшие в комплект, остаются
доступными как отдельная позиция. При наличии 1 комплект это безопасно; если
комплектов станет больше, нужно либо следить вручную, либо заводить
спецификацию.

## Отклонённые предложения (`aliases-rejected.json`)

Примеры: «систендница фулловая» — это тележка + N стендов, одним псевдонимом не
выразить; «флаг средний», «чокер», «рама трубная», «дом 125» — без размера
осознанно остаются на проверке; «b150 / б150» — до решения владельца.
