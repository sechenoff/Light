# Описания функций

Одна функция — один файл `ГГГГ-ММ-ДД-<тема>.md`. Отдельные файлы не конфликтуют
между параллельными PR двух агентов, общий `CLAUDE.md` — конфликтует. В `CLAUDE.md`,
в раздел «Описания функций», добавляется одна строка со ссылкой.

Пишем то, чего не видно из кода: зачем, какие решения принял владелец, какие
подводные камни уже встретились. Пересказывать код не нужно.

## Шаблон

```markdown
# <Название функции> (<ГГГГ-ММ-ДД>, PR #N)

**Зачем.** Какую проблему владельца решает. Факты с прода, на которых стоит решение.

**Где.** Страницы, маршруты API, сервисы, модели Prisma (новые поля и enum).

**Решения владельца.** Что выбрано и что сознательно НЕ сделано.

**Правила и инварианты.** Что нельзя ломать: гарды ролей, транзакции, аудит, коды ошибок.

**Подводные камни.** Что уже ломалось и почему.

**Тесты.** Какие файлы покрывают функцию.
```
