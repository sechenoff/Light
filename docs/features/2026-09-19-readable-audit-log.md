# Человекочитаемый журнал изменений (2026-09-19)

**Зачем.** Владелец хочет видеть, кто и из какого аккаунта внёс изменения, точные
дату и время, изменённые поля и понятные русские статусы. История нужна на карточке
брони и в общем журнале с отбором по сотруднику.

**Область работы (черновик).** API чтения аудита, русские подписи и отображение
разницы «было / стало», журнал администратора, история брони и переходы из списка
пользователей. Проверка записи автора и значимых изменений. Реализация и результаты
проверок будут описаны в этом документе до слияния PR.

**Правила и инварианты.** Доступ к общему аудиту остаётся у руководителя.
Существующие записи не переписываются, отсутствующие исторические сведения
не выдумываются. Пароли и токены в журнал не попадают. Изменение и его аудит
сохраняются в одной транзакции. Чужие открытые PR и рабочие папки сохраняются.
